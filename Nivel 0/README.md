# Práctica de Git

Mi primer repositorio para aprender Git y GitHub.

## Lo que estoy aprendiendo

- Crear repositorios
- Hacer commits
- Subir proyectos a GitHub
- Hacer uso de Markdown

## Conceptos aprendidos

- **¿Qué es la Mecatrónica?**
  - Es la combinación de cuatro áreas que trabajan juntas, entre las cuales se encuentran:
    1. Mecánica
    2. Electrónica
    3. Control
    4. Software
- **Git y GitHub**
  - Git es la herramienta que utiliza la terminal local para registrar, almacenar y modificar las versiones de un proyecto. GitHub es la versión web donde se puede subir un proyecto y exponerlo al público como portafolio.
  - Los 4 conceptos generales que se deben conocer referente a Git y GitHub son:
    1. **Repositorio**: Carpeta donde se almacena un proyecto y su historial.
    2. **Commit**: Es una "fotografía" del cambio que se realiza dentro del proyecto, con su respectivo mensaje.
    3. **Branch**: Rama que nos permite trabajar en una línea paralela para hacer pruebas y no afectar el proyecto principal.
    4. **Push**: Comando que nos permite subir nuestro proyecto local gestionado por Git a GitHub, incluyendo los commits realizados.
- **Técnica Pomodoro Personalizada**
  - Está téncica no está basada totalmente en un tiempo rígido, ejemplo 25-5, sino que es flexible según el momento en que se esté estudiando.
  - Para este caso personal la técnica está configurada como:
    - **Esudio**: 1 tema.
    - **Descanso**: Actividad diferente (una misión corta de un videojuego, lectura de un capítulo, organizar algo del trabajo, etc.).

## Comandos Git

| Comando | Función |
| :---: | :---: |
| init | Inicia un repositorio local |
| status | Revisa y muestra que archivos cambiaron, cuales están listos para realizar commit y cuales Git no sigue |
| add | Generalmente se usa ``add .`` que le indica que agregue a la "cola de espera para commit" a los archivos que han sido modificados |
| commit | Se usa comúnmente ``commit -m "mensaje"`` para crear y guardar el commit de los archivos previamente agregados con ``add`` |
| push | Sube el proyeecto y los commits realizados al portafolio creado en GitHub |
